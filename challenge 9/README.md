1.Start.
2.Initialize a 5×8 seating array with all seats as available (0).
3.Display the menu and read the user's choice.
4.Perform the selected operation:
- Display all seats.
- Book one available seat.
- Cancel an existing booking.
- Display the occupancy report.
- Reserve consecutive seats for a group.
- Exit the program.
5.Repeat the menu until the user selects Exit.
6.Stop.
